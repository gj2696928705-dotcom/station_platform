# 负荷与光伏预测之后：剩余算法任务总览

核对日期：2026-10-28。本文是后续开发会话的任务入口，依据当前代码和数据包整理；任务名与优先级是开发建议，不表示已经实现或通过生产验收。

## 已核对的起点

- 负荷和光伏已有独立候选模型及对接说明，但总平台场站任务仍返回 `forecast_status=not_used`；场站储能固定 `idle`。两个模型的站点、时间窗、计量口径及部署依赖尚未完成平台级闭环。
- 场站已有单站、未来一小时、4 个 15 分钟段的分车充电搜索、经济评价与站端硬校验；车队已有日前 CP-SAT 排班、场站服务优化、储能与 V2G 校核。后续应扩展并验证这些现有能力，不从零重复写。
- 总平台是同一部署入口，不是自动协同调度器；场站模拟站点、黄花站数据包和车队示例站点不能凭名字或比例混作同一场站。
- 2025 年负荷、光伏、设备台账和储能初态均为**模拟数据**。模拟回放能检验代码与约束，不能代替真实预测精度、设备控制或电网校核。

证据入口：[合并说明](../合并说明.md)、[场站代码](../../station_platform/domain.py)、[场站重算](../../station_platform/center.py)、[车队协作契约](../../fleet_platform/COLLABORATION.md)、[负荷接入约定](../../station_platform/docs/负荷预测适配验证与接入约定_v0.1.md)、[光伏接入约定](../../station_platform/docs/光伏预测对接说明_v0.3_day13.md)。

## 所有会话共用的约束

1. 先复查本文件所引源码与数据版本；交接文档中的未来状态和算法方案都是待实现要求，不是现有事实。保留用户本地改动，不覆盖原始模型、数据包或历史验收记录。
2. 时间统一带 `Asia/Shanghai` 时区、采用 `[start,end)` 区间及区间平均 kW；功率与电量用 `kWh = kW × 小时` 显式换算。任何缺口、晚到、站点/计量口径不匹配必须显式失败或降级，不用零值填补未知。
3. 将预测、量测、既有承诺和候选新计划分账；以 `as_of` 冻结可见信息，记录模型/数据版本、来源、哈希和任务/计划指纹。禁止把事后真值或未来天气放进历史决策输入。
4. 任何模拟计划保留 `simulation=true` 和可追溯证据。真实发布另需站点绑定、实测验证、设备/电网接口与运行审批；这些当前均未有完成证据。

## 本次不列为新算法的事项

预测模型接入封装、页面展示、模型依赖打包、统一身份和消息传输属于工程实现；真实设备协议、电网潮流与真实市场辅助服务需要外部业务契约。它们可能是算法落地前置，但现有证据不足以把它们描述为已具备或指定具体算法。车队的 CP-SAT 排班、储能优化及 V2G 提案已有实现，应先复验和复用；新任务集中在场站预测驱动及跨模块联合约束。
