# 黄花站 2025 年光伏模拟数据

本数据集是**完全合成的算法测试数据**，不是黄花站实测数据，也不是2025年气象再分析或实际运营记录。用途为验证光伏预测算法的数据读取、特征处理及实验流程；不能据此确定实站发电收益、实际预测精度或设备运行边界。

## 1. 文件与时间范围

- `黄花站_2025年_15分钟光伏模拟数据.csv`：全年主数据，35,040条，不含表头；365天，每天96点。
- `月度统计.csv`：12个月的模拟电量、峰值功率、水平面辐照量、降雨、温度与近似白昼时数。
- `simulation_config.json`：全部可调物理/天气参数、随机种子、来源与限制。
- `generate_huanghua_pv.py`：生成、复现和校验入口。
- `validation_report.json`：检查结果、年度统计、兼容性结果、SHA-256和运行环境版本。

时间从 `2025-01-01T00:00:00+08:00` 到 `2025-12-31T23:45:00+08:00`，采用 `Asia/Shanghai`，固定间隔15分钟。CSV为 UTF-8 BOM、逗号分隔、小数点为英文句点，数值保留6位小数；时间列保留显式时区。不要依赖表格软件自动转换后覆盖原始CSV。

## 2. 来源与模拟假设

| 项目 | 来源及本次处理 |

| 旧样例属性 | 旧JSON的模拟日期为2026-05-08，明确用于算法说明、接口设计和测试验证。它不提供2025年真实出力证据。 |

| 全年可用性 | 假设5 MW系统全年可用，不代表当年已建成投运，不包含故障、限发、检修、地形遮挡或积雪。 |
| 气象 | 按季节和连续随机过程合成，不下载气象数据，不使用官方气候常值，不对齐实际年电量。 |

原始资料的绝对路径、使用依据及可获得时的文件SHA-256保存在配置和校验报告中。模拟主表每行均带 `is_simulated=true`，数据说明中不把模拟标记替换为实测数据质量A/B等级。

## 3. 字段字典

| 字段 | 类型/单位 | 含义与使用注意 |
|---|---|---|
| `timestamp` | ISO 8601，+08:00 | 该行瞬时采样时间；也是降雨区间起点。 |
| `pv_power_kw` | float，kW | 采样时刻的聚合模拟输出功率，范围0～5,000；**不是15分钟平均功率**。 |
| `SWGDN` | float，W/m² | 水平面总短波辐照度，等同本数据集中的GHI。 |
| `DHI` | float，W/m² | 水平面散射辐照度。 |
| `DNI` | float，W/m² | 直接法向辐照度。 |
| `temperature_c` | float，℃ | 同步模拟环境温度，不是组件温度。 |
| `rain` | float，mm/15分钟区间 | `[timestamp, timestamp+15min)`累计降雨。**在区间结束后才可知，不能在区间开始时作为已知实测输入**。 |
| `cloud_cover` | float，0～1 | 同步模拟云量比例。 |
| `weather_type` | string | `clear`晴、`partly_cloudy`多云、`overcast`阴、`rain`雨；表示天气状态，雨天状态不要求每个区间都下雨。 |
| `solar_elevation_deg` | float，° | 几何太阳高度角；不含地形地平线、折射修正。 |
| `station_id` | string | 固定为 `HH-Huanghua-CSS`。 |
| `is_simulated` | boolean字面值 | 固定输出 `true`；读取软件可能自动转换为布尔值。 |

原参考代码未解释 `TP` 的含义，本数据不输出该歧义字段。当前算法的 `weather_columns` 支持显式选择列，因此温度使用 `temperature_c`。`PREV`、时间周期等特征由算法按时间构造，不在主表中预填可能引入泄漏的特征。

## 4. 生成方法

1. 以随机种子2025建立独立的天气、云量、温度、降雨、功率扰动随机流；先模拟7天预热，主表只保留2025年。
2. 采用NOAA分数年近似公式计算太阳赤纬、时间方程和太阳高度角。晴空水平辐照采用Haurwitz近似，夜间辐照与功率均为0。
3. 每6小时按季节概率及状态持续概率更新天气状态。云量逐15分钟向状态均值平滑趋近并带相关波动，避免每天复制同一条曲线。
4. 云量决定总辐照衰减及散射占比，严格保持 `SWGDN = DHI + DNI × max(sin(太阳高度角), 0)`。低太阳高度时的除法由显式阈值保护。
5. 温度包含月中均值插值、午后日变化、平滑插值的相关日异常、云量效应与小幅相关扰动。雨天使用具有持续性的湿/干区间及Gamma降雨量；阴天允许少量毛毛雨。
6. 以组件朝向、倾角计算直射入射角，采用各向同性天空散射模型和地面反射近似得到倾斜面辐照。根据NOCT估算组件温度，再由容量、温度系数、系统损耗和有界小幅扰动生成输出功率。

全部可调系数位于配置文件；太阳位置公式等固定数学系数随脚本版本保存。天气转移概率和温度月均值是模拟参数，不能解释为当地真实统计。没有人为将结果缩放至某个年发电量目标。

## 5. 电量、辐照量与月度统计口径

主表的功率为瞬时值，因此对相邻15分钟功率点按线性变化进行**梯形积分近似**：

```text
区间电量(kWh) = (P(t) + P(t+15min)) / 2 × 0.25
```

最后一段是2025-12-31 23:45至2026-01-01 00:00；按本模拟太阳几何，追加元旦00:00的夜间零功率作为积分端点，不另加到主表。跨月区间按起点归属月份。对 `SWGDN` 使用相同积分方式再除以1000，得到水平面辐照量kWh/m²。这些均为15分钟采样曲线的数值积分，不是电表结算或独立高频仿真真值。

- `simulated_energy_kwh`：该月模拟电量。
- `equivalent_full_load_hours`：该月模拟电量除以5,000 kW。
- `rainfall_mm`：直接累加该月区间降雨量，不再乘0.25。
- `mean_temperature_c`：该月各采样点环境温度的算术平均。
- `daylight_hours_approx`：太阳高度角大于0的点数乘0.25，仅为采样近似。
- `rainy_intervals`：降雨量大于0的区间数，不是雨天数。

年度统计以 `validation_report.json` 为准；月度表保留6位小数，求和误差应不超过舍入容差。

## 6. 使用与复现

需要Python 3.10+、NumPy、Pandas，以及项目已有的 `pv_forecast` 数据读取模块。已验证版本见校验报告；同一脚本、配置、NumPy/Pandas运行环境下，重复生成CSV逐字节一致。跨库版本的浮点末位不承诺完全相同。

在本目录执行（默认会重写本目录同名模拟CSV与校验报告）：

```powershell
python -B .\generate_huanghua_pv.py
python -B .\generate_huanghua_pv.py --validate-only
```

`--validate-only`保留现有CSV，只重新检查并刷新报告。若调整容量、天气系数或种子，应先修改配置，再生成到单独目录以保留原始版本：

```powershell
python -B .\generate_huanghua_pv.py --config .\simulation_config.json --output-dir .\另一个模拟版本
```

读取示例（在项目根目录执行）：

```python
from pathlib import Path
import sys

root = Path.cwd()
sys.path.insert(0, str(root / "代码" / "光伏"))
from pv_forecast.data import InputSpec, load_and_regularize, build_windows

path = root / "代码" / "数据" / "光伏数据" / "黄花站_2025年_15分钟光伏模拟数据.csv"
regular = load_and_regularize(path, InputSpec())  # 默认不使用气象
sample = build_windows(regular, target_start=288, target_end=289,
                       history_days=3, horizon_steps=96)
print(sample.history_power.shape)   # (1, 288, 1)
print(sample.target.shape)          # (1, 96)
print(sample.future_features.shape) # (1, 96, 5)，仅时间周期特征
```

只做同步气象分析或理想气象条件实验时，可显式选择：

```python
weather = ("SWGDN", "DHI", "DNI", "temperature_c", "rain")
regular = load_and_regularize(path, InputSpec(weather_columns=weather))
```

上述同步气象不是具有发布时间的历史天气预报。**不能把目标时段这些列当成真实预测发起时已经知道的未来特征**。尤其降雨字段包含未来15分钟的事后累计量。真正的日前/日内预测需额外提供在预测起点前已发布的气象预报，并按发布时间、目标时间对齐。

## 7. 校验范围

生成脚本自动检查全年覆盖、时区和时间间隔、缺失/非有限值、功率边界、夜间零值、辐照物理一致性、天气与跨日多样性、月年度积分一致性、随机种子复现及文件摘要。

兼容性检查调用已有 `load_and_regularize`，要求35,040行完整读取、缺失值为0、插值行数为0；分别为12个月构造3天历史和96点目标样本，同时检查纯时间特征与同步气象实验的特征形状。不会调用训练、TensorFlow推理、Hermes或设备控制。

**通过这些检查只表明模拟数据及接口可用，不表示已经验证模型训练、时间分区、泛化精度、发布能力或真实日前预测。**
