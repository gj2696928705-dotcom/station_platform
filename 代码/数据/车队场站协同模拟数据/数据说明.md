# 黄花站车队与场站协同模拟数据

本包执行 D03 推荐的绑定方案：以 D01 `HH-Huanghua-CSS` 为唯一站点，新建 4 个映射端口和小车队。`总平台/fleet_platform/domain.py` 的“示例充电站”配置是另一站点，未改名复用。黄花站其余 124 个端口未映射给本车队，亦未假装满载运营。所有内容为 2025 离线模拟，不代表真实车队、S1、电网确认或经济均衡。

运行：

```powershell
python -B .\generate_fleet_station.py
python -B .\validate_fleet_station.py
```

`simulation_config.json` 固定 D01 真值、费率规则、设备台账、储能参数及车队协作契约 SHA-256；`source_manifest.json` 保存来源清单。生成脚本只读来源，所有新文件在本目录。

## 场景与口径

同一业务日为 2025-09-15，北京时间 00:00–次日 00:00，共 96 段。`station_capacity_15m.csv` 的基础负荷取前一周同槽，PV 区间近似值取前一天同槽；源区间均在业务日 00:00 前结束，形成可复算的**全日过去数据基线**，不是 2026 候选模型在 2025 的发布预测。历史已发生充电真值不进入决策输入。已承诺充电 10:00–11:00 每段 80 kW 是独立模拟已知日程，占用车队子集外的 `SIM-G-005`，不是从 D01 未来会话偷取；容量表逐段记录其占用。费率沿用 D01 的模拟分时规则。PV 是不限发可用参考，服务中的 `pv_used_kw` 可低于它；无反送。

车辆充电功率是站点 AC 支路等效口径，电池能量增加量按 0.95 效率计算；未建 V2G 授权。`vehicle_energy_trace_15m.csv` 逐段记录充电、运输扣电和剩余电池能量，属于事后参考轨迹。储能 2 MW/4 MWh 参数取原包，但此夹具全日闲置，`site_dispatch_ready=false` 保留。`station_service_15m.csv` 与 `allocation_15m.csv` 给出非优化、可手算的完整分车服务实例，不声称最优。`fleet_aggregates_30_60m.csv` 从 15 分钟电量求和再除以时长；反向细分只以 `allocation_15m.csv` 的独占端口方案为证据。

| 场景 | 预期 |
| --- | --- |
| `F01_feasible` | 两车各 40 kW 持续一小时，可行小算例 |
| `F02_station_short` | 两车最低合计 80 kWh，车队分配容量 60 kW×1h，明确拒绝 |
| `F03_deadline_conflict` | 一车 10:30 前要 80 kWh，但 120 kW×0.5h 至多 60 kWh，明确拒绝 |
| `F04_cancel_reassign` | 旧预约确认取消后，新车复用端口并补 60 kWh |
| `F05_pressure` | 8 车、4 端口分两批各 120 kW/30min；不仿造 128 端口满载 |

`collaboration_messages.jsonl` 的 `adjustment/coordination_result/grid/reservation/execution/cancel_ack` 均含轮次、版本、指纹、时效、来源和模拟证据。`grid` 与 `S1` 消息是明确标记的模拟确认。`coordination_result` 中即使有完整服务，也将 `equilibrium.passed=false`：可行性手算并不能证明经济均衡，按车队契约应拒绝将其当作均衡确认。取消场景先有旧版预约、后有 `cancel_ack`，才发新版预约；重复同内容消息可去重，同 ID 不同内容应拒绝。

`history_uncontracted.csv` 保存 2025-08-01 至 09-30 每日 10:00–11:00 的单站未签约模拟真值。其电量由原历史充电的 10% 独立划作合成未签约组，仅供流程评测。已在目标时段前签约者不入标签，缺历史为空而非零，真实零值单独标记；以后转签的日期保留在真值中。`history_uncontracted_visible.csv` 截止 2025-09-15 00:00，只含已成熟标签，并遮掉当时尚未知的未来转签时间。训练为 8 月、校准为 9 月 1–14 日、回顾评测为 9 月 15–30 日。报告中的同槽均值 MAE 只证明流程可复现；原 2025 模拟数据已被查看，不能称全新盲测或真实预测精度。

独立校验读取所有来源重新核对 96 段网格、过去数据约束、端口独占、车辆 AC/电池能量、运输时间和储备、并网/PV/储能功率平衡、30/60 分钟 kWh、消息版本/取消顺序，以及历史可见时间与签约遮蔽。校验通过只证明本模拟包自洽。
