# 字段字典

所有 CSV 使用 UTF-8 BOM、LF；功率为 kW、电量为 kWh，时间为带 `+08:00` 的 ISO 8601。`station_id=HH-Huanghua-CSS`、`dataset_id`、`scenario_id`、`is_simulated=true`、`source_version(s)` 为通用身份与来源字段。空值表示不适用或未知，不是零。完整来源哈希在 `source_manifest.json`。

| 文件 | 关键字段与含义 |
| --- | --- |
| `identity_mapping.csv` | `fleet_station_id` 与唯一黄花站身份；`excluded_example_station_id` 明确排除另一示例站；`station_port_id/fleet_port_id` 映射；`station_port_rated_kw` 240、`fleet_port_limit_kw` 120、`connector` DC、`meter_boundary` AC 支路 |
| `vehicles.csv` | `vehicle_id,battery_kwh,initial_energy_kwh,initial_soc_percent,reserve_energy_kwh,max_charge_kw,max_discharge_kw,charge_efficiency,connector,v2g_authorized,available_from,available_until,available_at` |
| `transport_tasks.csv` | `task_id,vehicle_id,load_start/load_end,travel_start/travel_end,unload_end,deadline,travel_energy_kwh,mandatory,available_at`；截止指卸载完成时刻 |
| `charging_requests.csv` | `request_id,vehicle_id,station_id_ref,arrival_at,departure_deadline_at,min_ac_energy_kwh,target_ac_energy_kwh,priority,available_at`；电量在 AC 侧 |
| `station_capacity_15m.csv` | `business_date,timestamp,interval_end,as_of,available_at`；`load_source_end,pv_source_end,forecast_input_sha256` 固定过去数据；`base_load_forecast_kw,existing_committed_charge_kw,pv_available_forecast_kw`；并网限额、车队容量分配、映射/未映射端口、`existing_service_port_id,occupied_port_ids_json,other_ports_free_count`、储能状态和费率 |
| `allocation_15m.csv` | 每车每段 `vehicle_id,port_id,charge_power_kw,ac_energy_kwh,battery_energy_gain_kwh`；独占端口的细分证据 |
| `station_service_15m.csv` | `vehicle_charge_kw_json,fleet_charge_kw,existing_charge_kw,base_load_kw,pv_available_kw,pv_used_kw,pv_curtailed_kw,storage_charge_kw,storage_discharge_kw,storage_energy_after_kwh,grid_import_kw,grid_export_kw,fleet_capacity_kw,feasible_reference_fixture`；完整站级 AC 服务与功率平衡 |
| `fleet_aggregates_30_60m.csv` | `resolution_minutes,timestamp,interval_end,vehicle_ac_energy_kwh_json,grid_energy_kwh,grid_mean_kw,pv_used_energy_kwh,storage_net_charge_energy_kwh,aggregation_rule`；仅由 15 分钟电量守恒聚合 |
| `vehicle_energy_trace_15m.csv` | 每车每段 `energy_before_kwh,charge_gain_kwh,transport_energy_kwh,energy_after_kwh,soc_after_percent,charge_port_id,transport_task_id,available_at`；事后电池轨迹，不能放入决策输入 |
| `history_uncontracted.csv` | `business_date,timestamp,interval_end,label_available_at,split,label_status,uncontracted_energy_kwh,signed_at,quality`；`missing` 与 `signed_excluded` 的能量为空，`observed_zero` 为真零 |
| `history_uncontracted_visible.csv` | 在历史表基础上加 `as_of,future_signing_redacted`，未来转签时刻清空 |

`collaboration_messages.jsonl` 每条含 `message_id,task_id,kind,round_id,version,plan_fingerprint,issued_at,expires_at,received_at,source,evidence,payload,is_simulated,source_version`。契约要求的 `passed,reason,capacity_kw,service,equilibrium,status,confirmed` 在适用消息中位于顶层，并与 `payload` 一致。`source=grid/S1/coordinator` 只是模拟角色，`evidence.simulation=true`。`scenario_manifest.json` 保存各场景预期状态、绑定规模与来源哈希；`validation_report.json` 保存复算证据，产物哈希不含报告自身。
