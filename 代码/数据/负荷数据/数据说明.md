# 黄花站2025年全年15分钟负荷模拟数据

本目录是**完全合成的算法测试数据**。负荷、车辆到站、补能需求和充电会话均不代表实测或真实订单；温度只读复用本项目已有的2025年光伏模拟数据。数据没有用于训练或验证真实站点预测精度，不代表设备容量认证或运营收益。

## 1. 字段契约与计量边界

主文件为 `黄花站_2025年_15分钟负荷模拟数据.csv`，共 **35,040条**（不含表头），每天96条，覆盖2025年全年365天。使用 UTF-8 BOM、英文逗号、6位小数。

| 字段 | 类型/单位 | 含义 |
|---|---|---|
| `timestamp` | ISO 8601，+08:00 | 区间起点，2025-01-01 00:00至2025-12-31 23:45，时区Asia/Shanghai。 |
| `base_load_kw` | float，kW | **站用基础负荷**，排除车辆充电、储能充放电和光伏发电；非负。 |
| `charging_load_kw` | float，kW | 历史已发生的**模拟充电支路负荷**，非负；不是未来充电计划。 |
| `total_load_kw` | float，kW | 严格等于基础负荷加充电负荷；未扣光伏或储能，**不是并网净负荷**。 |
| `station_id` | string | 固定 `HH-Huanghua-CSS`。 |
| `is_simulated` | boolean字面值 | 固定为 `true`。 |
| `temperature_c` | float，℃ | 逐行复用光伏CSV相同时间的模拟温度；原数据为时间点的瞬时温度，不是区间平均温度，也不是天气预报。 |
| `is_weekend` | integer，0/1 | 普通日历的周六/周日为1；不包含法定节假日或调休修正。 |

**三个功率字段全部表示 `[timestamp, timestamp+15min)` 的区间平均功率，区间结束后才能完整获得。** 例如2025-01-01 00:00这行覆盖00:00～00:15；最后一行覆盖2025-12-31 23:45～2026-01-01 00:00。

电量计算为 `区间电量(kWh) = 区间平均功率(kW) × 0.25h`。本数据不得使用光伏瞬时功率数据的梯形积分口径，也不要把 `timestamp` 当作该区间平均功率已经被观测到的时间。

默认负荷模型目标是 **`base_load_kw`**，后续优化再叠加已有车辆会话和新充电计划；若另外训练 `total_load_kw`，它已经含历史充电负荷，不能再叠加一次充电计划。主表没有预制滞后量、滚动均值、未来实测值或预测结果。

## 3. 模拟方法

随机种子为 `20250928`，基础负荷与充电过程使用独立随机流。

**基础负荷：** 以旧模拟样例日内轮廓为起点，求每个15分钟区间内15个一分钟中点的平均轮廓，叠加周内系数、平滑季节系数、逐日相关扰动、区间相关扰动以及温度驱动的供暖/制冷用电。冷热用电采用一阶响应平滑，生成的是区间平均功率模型，不是每15分钟抽取一个瞬时值。

**充电负荷：** 日到站会话数服从带周内、季节及相关扰动修正的泊松过程，参考日均120个会话仅为假设。会话包括日间临时补能、晚间跨夜补能和清晨换班补能；各类到站分布、能量范围、120/180/240 kW功率取值及概率均可从配置查看。

充电会话从到站后安排到最早空闲端口，保证同端口不重叠。每个会话采用四阶段功率曲线，时间比例为12%/58%/20%/10%，功率比例为75%/100%/80%/50%，表示启动爬升、主要充电、末段回落的简化过程。开始、结束和阶段边界量化到一分钟。

分钟量化后，服务时长向上调整至覆盖请求电量，因此会话实际支路电量可能略高于生成的请求电量；两者分别记录，不把差额隐藏为损耗。支路功率不等同于电池侧充电功率，本轮没有另建电池侧效率、PCS损耗、SOC或停留占位模型。

脚本把分钟级会话功率先累加为15分钟能量，再换算为平均功率。使用2024年最后两天预热，保留跨入2025年的未结束会话；2025年末开始、延伸到2026年的会话仅将2025年内的电量计入主表。没有在每日零点强制清空会话。

基础与充电分量各量化为6位小数的整数定点数，然后相加得到总负荷。校验会读取导出的十进制字符串，逐行用 `Decimal` 验证严格守恒，避免将浮点误差当作分量不一致。

## 5. 复现与校验

需要Python 3.10+、NumPy、Pandas；已验证解释器与库版本保存在校验报告。本脚本不导入 `load_forecast`、XGBoost或TensorFlow，不训练模型、不改写模型代码，也不改写Hermes配置、项目交接文档或光伏数据。

在本目录执行：

```powershell
python -B .\generate_huanghua_load.py
python -B .\generate_huanghua_load.py --validate-only
```

生成命令会更新本目录同名负荷数据及报告。`--validate-only`保留CSV，刷新校验报告；检查失败时返回非零退出码并写入失败原因。光伏源文件的位置可用 `--temperature-source` 指定，但仍须匹配配置中的SHA-256。

另存实验版本：

```powershell
python -B .\generate_huanghua_load.py --output-dir .\另一模拟版本
```

同一参数、种子、输入温度和相同NumPy/Pandas环境下，主表、月度表、会话表重复生成均要求逐字节一致；源代码和运行库版本见报告。不同库版本的浮点末位不承诺完全相同。

读取主表时只需选择契约字段，不需要执行生成脚本或训练程序。例如在本目录：

```python
import pandas as pd

data = pd.read_csv("黄花站_2025年_15分钟负荷模拟数据.csv", encoding="utf-8-sig")
data["timestamp"] = pd.to_datetime(data["timestamp"], utc=True).dt.tz_convert("Asia/Shanghai")
target = data[["timestamp", "base_load_kw"]]
interval_energy_kwh = data["base_load_kw"] * 0.25
```
