# 字段字典

所有记录明确 `station_id=HH-Huanghua-CSS`、`scenario_id`、`is_simulated=true` 与来源版本；功率 kW、电量 kWh，时间为带 `+08:00` 的 ISO 8601。空字符串或 JSON `null` 为未知/不适用，绝非零。

| 文件 | 关键字段与含义 |
| --- | --- |
| `baseline_plan.csv` | `frozen_at,as_of,plan_version,plan_fingerprint,baseline_rule_version,market_baseline_rule_version`；`timestamp,interval_end,source_observation_end`；逐段基础预测、`existing_committed_charge_kw`（D02 已知 80 kW）、DR 分车功率 JSON、承诺 AC 电量、储能/PV 使用、预测净取电及并网限额。指纹绑定全部四段冻结内容 |
| `response_offers.csv` | `offer_id,direction,response_start/response_end,requested_power_kw,requested_energy_kwh,notice_lead_minutes,fixture_notice_lead_minutes,duration_minutes,recovery_start/recovery_end,recovery_fleet_power_cap_kw,authorized_resources_json`；市场基线/考核规则为 `unknown`，`market_status=not_applicable` |
| `activation_events.jsonl` | 每条含 `event_id,event_type,offer_id,plan_version,plan_fingerprint,business_time,available_at,received_at,source,source_ref,payload`；重复同 ID 同内容可去重，迟到以 `received_at` 判定 |
| `execution_truth.csv` | `timestamp,interval_end,available_at,received_at,activation_status`；真实基础/历史充电、D02 既有承诺电量与 DR 分车 AC 电量、PV 可用/利用、储能 AC 电量和新 SOC、并网购售电量、`measurement_quality,device_state_json,d02_event_ref,d02_event_applicability`；区间结束后才可用于评价，D02 事件引用仅作流程模式来源 |
| `baseline_mutation_attempts.jsonl` | 原基线指纹、篡改内容的新指纹、发生时刻和预期拒绝；不会覆写 `baseline_plan.csv` |
| `scenario_manifest.json` | 每场景的预期状态、约束、D02 来源事件、基线指纹与规则状态 |
| `rule_sources.json` | 审阅过的业务规则来源及“未知”结论 |
| `settlement_reference.json` | `status=not_applicable`，方法/允许偏差 `unknown`，金额与合格判定为 `null` |

`validation_report.json` 保存来源/产物 SHA-256、场景复算和证据边界；产物哈希不包含报告自身。
