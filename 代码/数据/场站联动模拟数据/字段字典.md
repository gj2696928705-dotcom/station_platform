# 字段字典

CSV 中的功率均为 kW，电量均为 kWh，时间均为带 `+08:00` 的 ISO 8601。布尔使用小写 `true/false`。空字符串表示不适用或未知，不表示零。所有文件使用 `station_id=HH-Huanghua-CSS`、`dataset_id=huanghua_linked_2025_offline_replay_v1`、`is_simulated=true`；`scenario_id=BASE_2025` 表示全年共享真值，`PACKAGE` 表示来源清单，其他 ID 表示窗口场景。`source_version(s)` 指明所用原包或本包假设版本，完整 ID 见 `simulation_config.json` 的 `source_versions` 映射。

## `station_interval_truth.csv`

| 字段 | 含义 |
| --- | --- |
| `timestamp`, `interval_end`, `available_at` | 区间起点、终点、事后真值最早可见时间；后两者相同 |
| `base_load_kw`, `historical_charge_kw`, `total_load_kw` | 原负荷基础分量、已发生充电分量及其严格和，15 分钟平均 |
| `base_energy_kwh`, `historical_charge_energy_kwh`, `total_load_energy_kwh` | 对应功率乘 0.25 小时，显示精度 6 位小数 |
| `pv_sample_start_kw`, `pv_sample_end_kw` | 原 PV 起点瞬时值及下一采样点；末段右端点为原说明规定的合成零锚点 |
| `pv_interval_mean_kw_approx`, `pv_interval_energy_kwh_approx` | PV 梯形积分所得近似区间平均及电量，不是电表量测 |
| `pv_conversion`, `pv_right_endpoint_source`, `pv_interval_quality` | 换算方法、右端点来源、近似质量标记 |
| `truth_view` | 固定 `post_interval_only`，禁止在本区间决策中使用 |

## 事件与请求

| 文件及字段 | 含义 |
| --- | --- |
| `booking_events.event_id`, `event_type` | 事件唯一 ID；`booking`、`cancellation`、`arrival` |
| `booking_events.event_at`, `available_at` | 模拟业务发生时间、决策系统可见时间；仅后者决定是否可用于 `as_of` |
| `booking_events.session_id`, `template_session_id` | 新生成的预约编号；后者只引用决策前结束的历史会话模板 |
| `booking_events.port_id`, `committed_energy_kwh`, `unit` | 模拟预约端口、承诺电量与单位；不含实际充电曲线 |
| `vehicle_requests.request_id`, `port_id` | 独立假设车辆请求及独占端口 |
| `vehicle_requests.available_at`, `arrival_at`, `departure_deadline_at` | 请求可见、到站、最晚离站时间 |
| `vehicle_requests.requested_energy_kwh`, `max_power_kw` | 请求电量和车/端口等效 AC 功率上限 |

## 预测

| 文件及字段 | 含义 |
| --- | --- |
| `forecast_vintages.vintage_id`, `resource` | 预测版本 ID，`load` 为基础负荷，`pv` 为不限发 PV 参考出力 |
| `issued_at`, `as_of` | 版本发布时间和决策时刻；可用版本要求前者不晚于后者 |
| `native_grid`, `window_start`, `window_end`, `point_count` | 原生网格、目标业务区间及实际点数 |
| `status`, `reason`, `selected` | 版本可用状态、原因、场景是否选中；选中不可用版本用于拒绝测试 |
| `method`, `method_sha256`, `bundle_sha256`, `input_sha256` | 方法说明、生成代码哈希、模型包哈希、输入观察值哈希；本包基线无模型包故该列为空；未运行的 day13 候选也不伪造包哈希 |
| `forecast_values.timestamp`, `interval_end`, `point_kw` | 区间起止和原生预测的区间平均功率 |
| `forecast_values.source_observation_end` | 构造基线的历史真值区间终点，必须不晚于 `issued_at` |
| `forecast_values.lower_kw`, `upper_kw`, `interval_kind` | 启发式上下界及类型；不声称统计覆盖率 |

## 场景决策输入

| 字段 | 含义 |
| --- | --- |
| `execution_mode`, `split`, `as_of`, `window_start`, `window_end` | 离线回放标识、时间分组、决策时刻和四区间窗口 |
| `load_vintage_id`, `pv_vintage_id`, `forecast_status` | 选中版本及总体预测可用性；缺口/晚天气场景应拒绝 |
| `commitment_status`, `visible_booking_count`, `request_count` | 预约承诺状态和决策可见计数；`unknown` 不能解释为零承诺 |
| `grid_import_limit_kw`, `grid_export_limit_kw` | 并网购电和反送上限，均为 AC 母线口径 |
| `available_port_count`, `port_rated_kw`, `derated_port_id`, `derated_port_max_kw` | 台账可用端口规模、单端口额定值及场景降额；设备可用不保证端口未被占用 |
| `storage_id`, `storage_state_available_at`, `storage_initial_soc_percent`, `storage_initial_energy_kwh` | 储能身份、模拟状态可见时间、窗口初态及能量 |
| `storage_max_charge_kw`, `storage_max_discharge_kw`, `storage_charge_efficiency`, `storage_discharge_efficiency` | PCS 场景功率上限及 AC 侧充放效率 |
| `storage_reserve_soc_percent`, `storage_soc_max_percent`, `storage_terminal_target_percent`, `storage_terminal_at` | 备用下限、上限、午夜目标及其时刻 |
| `storage_site_dispatch_ready` | 固定 `false`；局部动态验证不等于站级可调度 |
| `tariff_rule_id`, `expected_constraint`, `selection_basis` | 费率规则、预期应检验约束、事后选窗说明 |

## 逐区间费率与真值

| 文件及字段 | 含义 |
| --- | --- |
| `tariff_intervals.timestamp`, `interval_end`, `available_at` | 费率适用区间及决策可见时间 |
| `tariff_intervals.import_tariff_cny_per_kwh`, `export_tariff_cny_per_kwh`, `unit` | 模拟购售电价及 CNY/kWh 单位；售电价 0 不代表允许反送 |
| `scenario_truth.timestamp`, `interval_end`, `available_at`, `truth_view` | 场景事后真值的区间和可见时间；固定 `post_interval_only` |
| `scenario_truth.base_load_kw`, `historical_charge_kw`, `total_load_kw` | 从全年真值按时段引用的基础/已发生充电/合计负荷 |
| `scenario_truth.pv_interval_mean_kw_approx`, `pv_interval_energy_kwh_approx` | 同期不限发 PV 梯形积分近似 |
| `scenario_truth.import_tariff_cny_per_kwh` | 对应区间的模拟价格副本，便于事后评价；决策以 `tariff_intervals` 为准 |

`source_manifest.json` 的每条对象含站点、场景、模拟标记、相对 `代码/数据` 的来源路径、SHA-256、是否固定在配置中及只读标记。`validation_report.json` 的 `output_hashes_sha256` 不包含报告自身，以避免循环哈希。
